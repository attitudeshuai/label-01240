**需求分析**

这是一个局域网广告图片预览系统，需要：
1. **后端管理端**：管理部门、上传图片、配置播放参数
2. **前端展示端**：展示广告图片、支持多种播放模式
3. **实时同步**：WebSocket 实现配置变更实时推送

**项目架构**

```
├── backend/                 # 后端服务 (Python FastAPI)
├── frontend-admin/          # 管理后台 (Vue3 + Element Plus)
├── frontend-user/           # 用户展示端 (Vue3 + 黑金风格)
├── docs/                    # 项目文档
├── docker-compose.yml
├── .gitignore
└── README.md
```

**技术栈：**
- 后端: Python 3.11 + FastAPI + SQLAlchemy + SQLite
- 前端管理: Vue 3 + Vite + Element Plus + Pinia
- 前端展示: Vue 3 + Vite + 原生 CSS（黑金风格）
- 实时通信: WebSocket
- 部署: Docker + Docker Compose

**核心功能实现：**

1. **部门管理** (`backend/app/services/department_service.py`)
   - 部门增删改查
   - 默认初始化 A、B、C 三个部门

2. **广告管理** (`backend/app/services/advertisement_service.py`)
   - 广告图片上传
   - 支持多种比例：16:9、4:3、1:1、9:16
   - 按部门分类管理

3. **播放配置** (`backend/app/services/play_config_service.py`)
   - 播放模式：循环播放、单次播放、手动翻看
   - 播放间隔：1-30秒可调
   - 自动播放开关

4. **WebSocket 实时同步** (`backend/app/services/websocket_manager.py`)
   - 配置更新实时推送
   - 广告列表更新实时推送
   - 部门列表更新实时推送

5. **用户展示端** (`frontend-user/src/App.vue`)
   - 黑金风格 UI 设计
   - 部门切换
   - 播放控制（播放/暂停、上一张/下一张）
   - 播放模式切换
   - 进度条显示
   - 响应式布局

**启动方式：**

# 访问地址

用户展示端: http://localhost:8081/user/
